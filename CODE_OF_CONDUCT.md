# Microsoft Open Source Code of Conduct

This project has adopted the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).

Resources:

- [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)
- [Microsoft Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)
- Contact [opencode@microsoft.com](mailto:opencode@microsoft.com) with questions
  about the Microsoft code of conduct itself

This is an independent community repository, not a Microsoft-owned project.
Report conduct concerns about this project privately to its maintainer through
[GitHub Security Advisories](https://github.com/ppiova/mai-foundry-demos/security/advisories/new).
This route is also available for confidential community reports; do not post
personal details in a public issue. The maintainer, not Microsoft, handles
reports about this repository.
